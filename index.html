关于文件重命名工具

此工具批量重命名文件夹中的文件。您可以按照文件名或修改时间对文件进行排序，并按照指定前缀和编号格式重命名文件。所有处理均在您的浏览器中完成，文件数据不会发送到服务器。

关于合并/拆分序列图集

此工具提供两个功能：1) 将多张序列图合并为一张序列图集，可配置行列数和排列方向；2) 将单张序列图集拆分为多张序列图，可配置行列数和提取方向。所有处理均在您的浏览器中完成，图片数据不会发送到服务器。

注意：导出的图片为PNG格式并保留透明通道。合并功能需要所有图片尺寸一致。拆分功能需要知道原始序列图集的行列数。

关于完美像素

此工具将模糊的AI生成像素图精炼为干净完美的像素图。通过自动检测像素网格或手动指定2的次幂分辨率，结合边缘精炼和多种采样方法，输出清晰的像素艺术作品。算法参考 perfectPixel。

注意：处理大尺寸图片可能耗时较长。 所有处理均在浏览器本地完成，数据不会发送到服务器。

关于工作流

蓝图节点是一个可视化编程工具，通过拖拽和连接节点来构建素材处理流水线。支持加载图片、调整大小、翻转旋转、裁剪、色彩调整、灰度化、阈值、混合和导出等操作。

操作提示：从右侧面板拖拽节点到画布，或在画布上右键搜索节点。从节点输出端口拖线到输入端口建立连接。点击执行按钮运行整个流程。所有处理均在浏览器本地完成。

关于 AI 去背景

此工具使用 AI 模型 RMBG-1.4（168MB）智能移除图片背景，效果与 ComfyUI 完全一致。首次使用时需要加载模型，之后浏览器缓存即可秒开。

技术链：

  • 模型：BriaRMBG-1.4 — BriaAI 高精度背景移除模型，与 ComfyUI-Easy-Use 效果一致
  • 推理：ONNX Runtime Web — 微软开源端侧推理引擎
  • 参考：ISNet / BEN2 等 ComfyUI-Easy-Use 中的去背景实现

注意：所有处理均在您的浏览器本地完成，图片数据不会发送到服务器。由于 WebAssembly 限制，须通过 HTTP 服务器打开（双击 start.bat）。建议使用支持 WebGPU 的现代浏览器以获得最佳性能。

此功能仅支持本地使用（localhost / 127.0.0.1），GitHub Pages 等在线托管平台因 HTTP/2 大文件传输限制无法运行。
